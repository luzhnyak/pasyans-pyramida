# Пасьянс «Піраміда»

Статична гра на JavaScript і Canvas. Відкрийте `index.html` у браузері
або опублікуйте корінь репозиторію на будь-якому статичному хостингу.
Збирання та встановлення npm-залежностей не потрібні.

## Правила

Прибирайте відкриті пари із сумою 13; король прибирається окремо.
Туз — 1, валет — 11, дама — 12, король — 13.
Карта піраміди відкривається після видалення обох карт під нею.
Резерв перегортається по одній карті, грає лише верхня відкрита карта.
Вичерпаний резерв можна перегорнути знову. Перемога — очищена піраміда.
Поточний варіант гри показує закриті карти піраміди сорочкою вгору.

За короля або пару нараховується `1 + bonus` очок, після чого бонус зростає
на 1. Перегортання наступної карти резерву зменшує бонус на 1 до мінімуму 0.

## Перевірки

Потрібен Node.js 22 або новіший, лише для розробки:

```sh
npm run check
npm test
```

Тести запускають справжній ігровий скрипт у Node VM з адаптерами DOM,
Canvas і мережі. Вони перевіряють правила, повторний запуск, резерв,
масштабування координат і надсилання результату. Візуальне відображення
та реальний Telegram API потребують перевірки в браузері.

## Telegram

Кнопка «Поділитися» викликає TelegramGameProxy за його наявності.
Після перемоги результат надсилається один раз за роздачу на наявний
endpoint `https://luzhnyak.pp.ua/setscore/piramida`, лише якщо URL містить
`user_id` та `inline_message_id`. Параметри кодуються через URLSearchParams.
Сервер повинен самостійно перевіряти авторизацію та результат:
клієнтські параметри не є доказом права оновлювати Telegram score.
Серверного коду в цьому репозиторії немає.

## Структура

- `index.html`, `js/script.js`, `img/` — поточна Canvas-версія.
- `html/` — попередня DOM-версія, не використовується головною сторінкою.
- `css/style.css` — старі стилі; поточна сторінка використовує inline CSS.
- `tests/` — регресійні тести без сторонніх залежностей.
